

### ТЕХНИЧЕСКОЕ ЗАДАНИЕ
**на вакансию Разработчик C/C++в команду прошивки (с упором на опыт с модемами)**

Реализуйте приложение-сервер на с/с++, который прослушивает tty устройство и отвечает на AT команды.

Словарь ожиданий в виде ограниченного синтаксиса регулярных выражений(точка - один любой символ, * - ноль или 
любой символ)и ответов к ним разместить в csv файле или текстовом файле expect=answer.

Базовый тестовый набор команд: AT, ATE[1,0],  ATI, AT+COPS, AT+CPIN.

Нельзя использовать библиотеку для разбора регулярных выражений в решении.

#### ИЗМЕНЕНИЯ К ТЗ (согласовано в чате)
При формате словаря (expect=answer) невозможно надежно отделить команду установки от разделителя словаря.  
Поэтому (согласовали в чате: "На усмотрение") добавляю два символа "\r" в конце каждой команды.   
  Таким образом, разделитель словаря становится "\r=" (ВАЖНО: это два отдельных символа "\" и "r", а не 0x0D).
Такая комбинация не может встречаться в команде и служит надежным определителем.

Пример файла со словарем:
```text
ATE1\r=OK
ATE0\r=OK
ATE4\r=ERROR
AT+CPIN\r=ERROR
AT+CPIN?\r=+CPIN: "READY"
```

### Запуск сервера
1) Собираем проект через CMake, создастся папка bin с сервером (at_server) и тестовым словарем.
2) Открываем 3 терминала:
   - **Терм_1** - создаем через socat трубу из двух pts (в raw режиме), видим какие pty создались, например: /dev/pts/X, /dev/pts/Y  
     ```> socat -d2 PTY,raw,echo=0 PTY,raw,echo=0```  
     Будет выведена информация о запуске. В случае критических ошибок сервер не запустится.  
   - **Терм_2** - запускаем собранный at_server, в строке указываем терминал tty и путь к словарю    
     ```> ./at_server_01 --cfile vocab_default.txt /dev/pts/9 ```
   - **Терм_3** - запускаем microcom (утилита для работы с COM-портами):  
     ```> microcom -p /dev/pts/Y```
3) Можем вводить команды в Терм_3  
   ```AT``, при этом вводимые символы будут отображаться в консоли (режим ATE1 по-умолчанию), после ввода сервер ответит: "OK"

### Правила заполнения Словаря:
1) Текстовый файл в формате: ```expect=answer```, где:  

    ```expect``` - ОДИНОЧНАЯ команда, с префиксом "AT" или "at", заканчивающаяся двумя символами "\" и "r".  
         В команде допускается ограниченный синтаксис регулярных выражений:  
         - точка - один любой символ,   
         - звездочка (астерикс) - любое кол-во символов.  

    ```answer``` - текст, выводимый на экран при совпадении введенной команды с командой из словаря.  
        Должен заканчиваться переносом строки (LF или CRLF).  

2) Цепочки команд (через ;) - в целом работают, но интерпретируются как одна команда.  

3) При использовании набора регулярок [*.] более жадные команды должны идти после менее жадных.
     Команда AT*\r=OK в начале словаря "сожрет" все команды после себя.


### Правила ввода команд:
1) Цепочки команд (через ;) - Работают только как одиночная команда (введенная команда должна полностью совпасть со словарем). Раздельная обработка каждой команды в цепочке не реализована.   
2) Команды ATE[0,1] - обрабатывают вывод в коде, независимо есть они в словаре или нет. Если в словаре есть, то ответ будет взят оттуда, иначе "OK".   
3) Работает команда повтора предыдущей команды "A/" (без ожидания терминатора).
